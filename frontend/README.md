# Prowl Dashboard

React frontend for **Prowl**, a small wheeled robot with a camera and LiDAR, built at GeauxHack. Theme: "Life in Space".

> **Demo mode.** The dashboard does not connect to the robot yet. Everything on screen is placeholder or clearly labeled sample data. The connection method and data formats are not decided.

## Run it

You need Node.js. Then, in this folder:

```bash
npm install
npm run dev
```

Open the address that `npm run dev` prints (usually http://localhost:5173/).

## What is here so far

- Header with the Prowl name and a connection status (currently always "Disconnected")
- "Demo mode — robot not connected." banner
- Placeholders for the map and the camera
- An observations panel (empty for now)

Built with React, Vite, JavaScript and plain CSS. No UI library.
